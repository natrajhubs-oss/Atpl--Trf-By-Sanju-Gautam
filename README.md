ATPL Digital TRF
Standalone ATPL Digital Test Requisition Form for GitHub Pages.
Publish with GitHub Pages
Create a GitHub repository.
Upload index.html to the repository root.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select main and / (root), then save.
Wait a few minutes for GitHub Pages to publish.
The site is self-contained and does not require external CSS, JavaScript, or API files.# Atpl--Trf-By-Sanju-Gautam
